## What Changed

**The row count is fixed.** v1 declared 320 and contained 318. The two missing components were `State=waitingForProvider` (`16127:157356`, `16127:157531`) on the Cards page — loose variants sitting outside their component set. **320 is the real number.**

**Categories are stated, not guessed.** v1 had only Figma node types; category came from a name-prefix heuristic. 135 components now carry a real atomic category from Layer 2.

**Token bindings exist.** Every component's `boundVariables` were walked recursively — fills, strokes, spacing, radius, typography, sizing. This is the edge that connects [Layer 1](../layers/01-tokens.md) to Layer 3, and it did not exist before.

**The JSON is no longer lossy.** `component-usage.json` is an array, so the 19 duplicated names all survive.

## Known Defects

**19 duplicated names.** Same name, different node ids. Resolve by `id`, never by name:

```bash
python ../scripts/arc_query.py --index relationships/component-usage.toon duplicates
```

**170 orphans (of 320).** BETA (78) and top-level patterns are legitimate roots; the remainder needs triage.

**185 components uncategorised** — those without Layer 2 metadata. The query engine falls back to a name-prefix heuristic for them and says so.

**111 legacy token references.** See [Layer 1](../layers/01-tokens.md#4-audit--what-the-export-reveals) — variables bound in components that do not exist in `tokens.json`.
